Esta é uma API RESTful para **controle de estoque** e **gestão de pedidos**, desenvolvida para auxiliar na automação de processos de venda e gerenciamento de produtos. A API permite o cadastro, atualização, exclusão e consulta de produtos no estoque, bem como a criação e acompanhamento de pedidos realizados.

## 📝 Sobre o Projeto

O objetivo desta API é fornecer uma solução eficiente para o gerenciamento de estoques e pedidos de forma automatizada, permitindo a integração com sistemas de vendas, marketplaces ou plataformas de e-commerce.

### Funcionalidades Principais:

- **Gerenciamento de Produtos**: CRUD de produtos (criar, ler, atualizar e deletar).
- **Controle de Estoque**: Atualização automática de estoque ao registrar vendas e pedidos.
- **Gerenciamento de Pedidos**: Criação de pedidos com itens do estoque, cálculo de total de pedidos e controle do status.
- **Consulta de Produtos**: Pesquisa de produtos por nome, categoria, ou código de barras.
- **Relatórios**: Geração de relatórios de pedidos e estoque (a ser implementado).
